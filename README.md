  <h2 class="home-section__title">🌿 技术理念</h2>
  <div class="home-philosophy">
    <div class="home-philosophy__card home-philosophy__card--arch">
      <span class="home-philosophy__icon">🏛️</span>
      <h3 class="home-philosophy__name">架构思维</h3>
      <p class="home-philosophy__desc">
        不是微服务框架，而是演化架构；不是新的编程语言，而是整洁的代码、设计模式和 DDD；不是 Hystrix，而是容错模式。架构的本质是权衡与决策，而非框架的堆砌。
      </p>
    </div>
    <div class="home-philosophy__card home-philosophy__card--ai">
      <span class="home-philosophy__icon">🤖</span>
      <h3 class="home-philosophy__name">AI 探索</h3>
      <p class="home-philosophy__desc">
        大语言模型正在重塑技术格局，从 Prompt Engineering 到 RAG 架构，从 Agent 系统到多模态应用。拥抱 AI 不是选择，而是技术人的必修课。
      </p>
    </div>
    <div class="home-philosophy__card home-philosophy__card--tech">
      <span class="home-philosophy__icon">💡</span>
      <h3 class="home-philosophy__name">技术哲学</h3>
      <p class="home-philosophy__desc">
        参考二八原则，将 80% 的学习时间投入到基础知识上。不是 Docker，而是持续交付、容器化；不是 Angular，而是 Web、HTTP 和 REST。将技术看作思想的实现，却莫本末倒置。
      </p>
    </div>
