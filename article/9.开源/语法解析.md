# 语法解析

## 介绍

### 1.分类

主流的语法解析器（Parser）工具根据应用场景（如编译原理、配置文件解析、领域特定语言 DSL 开发等）可分为几大类：

一、通用多语言解析器生成器：这类工具支持通过语法规则（如 EBNF）自动生成解析器，适用于开发编程语言、复杂 DSL 等。
1. Yacc/Bison
    - 特点：经典的 LR 解析器生成器，Yacc（Yet Another Compiler-Compiler）是 Unix 时代的元老，Bison 是 GNU 对 Yacc 的增强版，支持更丰富的语法特性。
    - 适用场景：编译原理（如 C/C++ 编译器前端）、传统编程语言解析。
    - 缺点：语法规则编写较繁琐，对新手不友好，不支持直接生成现代编程语言（如 Python/Java）的解析器代码。
2. Lex/Flex + Yacc/Bison
    - 组合使用：Flex（Lex 的增强版）负责词法分析（Token 提取），Bison 负责语法分析，是传统编译工具链的黄金组合。
    - 案例：很多 Unix 工具（如 `awk`、`bash`）的解析器基于此组合开发。
3. GNU Bison
    - 作为 Bison 的升级版，支持更多语法类型（LR、LALR、GLR 等），可生成 C、C++、Java 等语言的解析器代码。

二、现代高级解析器生成器：针对 ANTLR 的不足（如性能、特定语法支持）优化，或提供更简洁的语法定义方式。
1. PEG.js
    - 特点：基于 PEG（Parsing Expression Grammar，解析表达式语法）的 JavaScript 解析器生成器，语法规则与正则表达式类似，简洁易读。
    - 适用场景：前端领域的 DSL 解析（如自定义模板语法、配置文件解析）。
    - 优势：无需单独处理左递归，自带词法分析能力，可直接在浏览器或 Node.js 中使用。
    - 案例：Vue 模板解析早期版本曾参考 PEG.js 思想。
2. Chevrotain
    - 特点：用 TypeScript 编写的 PEG 解析器工具库，支持生成类型安全的解析器，适合 TypeScript/JavaScript 项目。
    - 优势：性能优于 PEG.js，支持复杂语法和错误恢复，文档丰富。
3. Menhir
    - 特点：OCaml 语言的 LR 解析器生成器，支持模块化语法定义和强大的类型检查，适合函数式编程场景。
    - 适用场景：OCaml 生态中的编译器或 DSL 开发。

三、领域特定解析器工具:针对特定场景（如配置文件、数据格式）优化，无需编写完整语法规则。
1.  Lark
    - 特点：Python 生态的解析器库，支持 EBNF 语法，自动选择最佳解析算法（LR、PEG 等），开箱即用。
    - 优势：零依赖，语法简洁，支持自动生成抽象语法树（AST），适合快速开发 Python 中的 DSL 或配置解析器。
    - 案例：用于解析自定义日志格式、简化版 SQL 等。
2. PyParsing
    - 特点：Python 的另一个解析库，采用“面向对象”的方式定义语法（而非 EBNF 字符串），灵活性高。
    - 适用场景：快速开发小型解析器（如命令行参数解析、简单表达式计算）。
3. ANTLR 的替代者：Babel Parser
    - 特点：专门用于 JavaScript/TypeScript 解析的工具（基于 ESTree 规范），是 Babel 编译器的核心。
    - 适用场景：前端代码转译、静态分析（如 ESLint、Prettier 依赖其进行语法解析）。

四、基于 LL 算法的解析器工具：LL 算法（自顶向下解析）实现简单，适合手写或生成简单语法的解析器。
1. RecDescent
    - 特点：Perl/Python 中的递归下降解析器生成器，语法规则与代码逻辑结合紧密，适合简单语法。
    - 优势：易于调试，适合手写解析器时参考其思想。
2. JavaCC（Java Compiler Compiler）
    - 特点：Java 生态的 LL 解析器生成器，支持生成 Java 代码，曾用于 Java 编译器的早期版本。
    - 缺点：对复杂语法（如左递归）支持较弱，目前逐渐被 ANTLR 替代。

五、工业级专用解析器：用于特定编程语言或协议的解析，通常由官方或社区维护。
1. libpg_query
    - 特点：PostgreSQL 官方的 SQL 解析器库，可直接解析 SQL 语句并生成 AST，适合数据库相关工具开发。
2. Tree-sitter
    - 特点：由 GitHub 开发的增量解析器，支持多语言（如 JavaScript、Python、C++），可高效处理代码编辑时的语法树更新。
    - 适用场景：代码编辑器（如 VS Code、Atom）的语法高亮、自动补全功能。

### 2. 选型建议
- 复杂语言/跨语言：优先 ANTLR（支持 40+ 目标语言，生态完善）。
- 前端/JavaScript：PEG.js 或 Chevrotain（简洁且适配前端环境）。
- Python 快速开发：Lark 或 PyParsing（零依赖，语法简单）。
- 传统编译场景：Bison + Flex（兼容性好，适合 C/C++ 生态）。
- 代码编辑器/IDE：Tree-sitter（增量解析，性能优异）。

## ANTLR 
ANTLR（Another Tool for Language Recognition）是目前最流行的语法解析框架之一，它支持从语法文件生成 Java 解析器。

ANTLR 是一个强大的语法分析器生成器
1. 根据 .g4 文件自动生成词法分析器（Lexer）与语法分析器（Parser）
2. 支持语义分析、AST 抽象语法树
3. 提供监听器（Listener）与访问器（Visitor）模式
4. 语言支持广泛（Java、Python、Go、C# 等）。
