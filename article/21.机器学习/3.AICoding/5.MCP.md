# 5.MCP

MCP是大模型应用的扩展，能大模型能够主动的探索外部资源

推荐使用的MCP包括：
1. Playwright — 自动操作浏览器：让AI帮你打开网页、点按钮、填表单、截图。自动发帖、批量截图、抢票思路都靠它。
2. Desktop Commander — AI接管你的电脑：它能跑终端命令、管理进程、搜索文件内容，还能像你一样操作整台电脑。
3. GitHub — 操作代码仓库：直接在对话里提PR、查Issue、做代码审查、管理仓库。
4. Context7 — 让AI不再瞎编代码：目前最火的MCP之一。它会自动把你用的技术框架的最新文档注入给AI，参考的是真实文档而不是它自己的记忆。
5. Firecrawl — 抓网页内容：能把整个页面内容抓下来变成干净的文本给AI分析，做竞品调研、批量采集数据，都可以用。
6. Fetch — 轻量版网页读取：和Firecrawl类似但更轻。给一个URL，直接读取内容。适合快速看一篇文章、拉一个API的返回结果、读一个在线文档。
7. PostgreSQL / SQLite — 直接操作数据库：帮你查数据、建表、跑SQL、做数据分析，对有数据库的项目来说是刚需。
8. Sequential Thinking — 让AI学会分步思考：Anthropic官方出的，遇到复杂问题时，它会让AI把任务拆解成多个步骤，一步一步想清楚再动手。
9. 飞书 MCP — 连接你的办公工具：能读写飞书文档、操作多维表格。帮你写周报、更新项目进度表、整理会议纪要，直接写进飞书里。
10. Excel MCP — AI直接帮你做表：读写Excel文件、写公式、操作工作表。丢一个表给它说“按月汇总销售额，加个同比增长列”，它直接改好给你。
