# 3.小说


```text
AI小说生成
1. 初始化
sudo apt update
sudo apt install python3-venv -y
python3 -m venv torch-env

2. 启动虚拟环境
cd /data/python
source torch-env/bin/activate
pip install torch numpy websockets

3. 关闭虚拟环境
deactivate

4. 运行服务
cd torch-env
git clone https://github.com/BlinkDL/AI-Writer.git
cd AI-Writer
在 run.py 和 server.py 设置为 cpu 模式
python run.py  命令行模式
server.py          webUI模式

快速使用：
source /data/python/torch-env/bin/activate
cd /data/python/torch-env/AI-Writer
python run.py
```
