Ruflo · 多智能体编排

硬核数据

  • 100+ Agent 角色
  • 210+ MCP 工具
  • 32 原生 + 21 npm 插件
  • AgentDB(HNSW)记忆,快 150x-12,500x
  • Token 优化 30-50%

5 种 Swarm 拓扑

  • Hierarchical:Queen + Workers,大项目
  • Mesh:互通无中心,探索任务
  • Ring:流水线,代码→测试→review
  • Star:Hub 路由,轻协调
  • Adaptive:系统自动选
⚠️ 冷静看:Ruflo 描述能力很激进(100+ agents、enterprise security),Reddit 有质疑宣传与实际差距;每天发版,建议 pin 版本;不要直接上生产,先非关键项目试

Compounding Engineering · Plan-Work-Review

阶段命令做什么
Plan/ce:plan模糊想法 → 结构化 GitHub Issue(研究代码库 + 验收标准)
Work/ce:work独立 git worktree + 持续验证 + 测试覆盖
Review/ce:review并行 12+ 评审 agent(安全 / 性能 / 架构 / 质量)
💡 核心理念:质量应该是<复利>的,不是线性的。每完成一个功能,下次起点应该更高,不是拉平。

claude-squad · Git Worktree + 并行 Claude

4 种使用模式

  • 特征探索:3-4 Claude 不同方法实现同功能
  • 竞争实施:同 prompt 多 Claude,赌一次就对
  • 专业代理:不同 Claude 做不同方面
  • 官方推荐:gw.sh / gwr.sh 一键 worktree
