选型决策树

技术能力?
├ 不会写代码   ─▶ Coze Studio(5 分钟出 Bot)
├ 产品 / 运营   ─▶ Dify / Coze(可视化)
├ 后端工程师   ─▶ n8n / Dify
├ Python 工程师 ─▶ LangGraph(精细控制)
└ LC 深度用户   ─▶ LangFlow / Flowise

核心诉求?
├ 跨系统自动化(Slack+DB+邮件) ─▶ n8n ★★★★★
├ 企业 AI 应用 + RAG           ─▶ Dify ★★★★★
├ C 端 Bot / 多平台发布        ─▶ Coze ★★★★★
├ 复杂多 Agent 协同            ─▶ LangGraph ★★★★★
├ 专业文档(法律/金融/医疗)    ─▶ RAGFlow ★★★★★
└ 快速原型 / 内部工具          ─▶ Flowise / LangFlow

数据主权?
├ 必须本地(金融/政务) ─▶ n8n / Dify / RAGFlow(自托管)
└ 不强求              ─▶ 看体验选

商用模式?
├ 自用 + 内部工具     ─▶ 任何平台都 OK
├ 做 SaaS 卖客户      ─▶ 避 n8n / Dify 多租户限制 → LangGraph / RAGFlow / Flowise
└ 嵌入到产品里        ─▶ MIT / Apache 优先 → LangGraph / Flowise / LangFlow
