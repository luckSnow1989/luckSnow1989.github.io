🧪 Spring Cloud 单测黄金组合(测试金字塔)

E2E
少量 / 关键路径
集成测试(Testcontainers)
真实 MySQL/Redis/Nacos
单元测试(JUnit 5 + Mockito + AssertJ)
Service 逻辑 80%+ / 工具类 100%

覆盖指标(硬指标)

  • Service 核心:行 ≥ 80% / 分支 ≥ 70%
  • Controller:行 ≥ 60%
  • 工具类:100%
  • Mapper/Entity:不要求(框架自动)
  • 命令: mvn test jacoco:report
  • 报告: target/site/jacoco/index.html

测试要点

  • ✅ 每个验收标准都有对应测试
  • ✅ 边界条件(刚好/多一点/少一点)
  • ✅ 异常路径(空指针/超时/找不到)
  • ✅ Mock 隔离,不依赖 Spring 上下文
  • ❌ 不为覆盖率凑数
  • ❌ 测试代码不 commit(不跟生产代码 review)
