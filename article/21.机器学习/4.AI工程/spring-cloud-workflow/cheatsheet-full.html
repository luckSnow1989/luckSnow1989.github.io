5 分钟上手命令

# 1. 装 CC
npm install -g @anthropic-ai/claude-code

# 2. 装 Superpowers
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

# 3. 装 planning-with-files
/plugin marketplace add OthmanAdi/planning-with-files
/plugin install planning-with-files@planning-with-files

# 4. 验证
/help  # 应该看到 /superpowers:brainstorm 等

# 5. 跑一个需求

关键命令速查

Superpowers 命令

  • /superpowers:brainstorm 需求澄清
  • /superpowers:write-plan 写实施计划
  • /superpowers:test-driven-development TDD
  • /superpowers:requesting-code-review 审查
  • /superpowers:use-git-worktree 隔离
  • /superpowers:systematic-debugging 调试

Spring Cloud 测试命令

  • mvn test 跑单测
  • mvn test jacoco:report 覆盖率
  • mvn -Dtest=ClassName test 跑单个
  • mvn -pl order-service test 跑指定模块
  • 报告: target/site/jacoco/index.html

Git Worktree

  • git worktree add ../分支名 -b feature/xxx
  • git worktree list
  • git worktree remove ../分支名

Claude Code 命令

  • /clear 清空上下文
  • /compact 压缩上下文
  • /init 生成 CLAUDE.md
  • /help 帮助

覆盖率硬指标(分级)

层行覆盖分支覆盖说明
Service 核心≥ 80%≥ 70%硬指标,不达标不合并
Controller≥ 60%—可协商
工具类100%100%纯函数,好测
Mapper/Entity不要求—框架自动生成
