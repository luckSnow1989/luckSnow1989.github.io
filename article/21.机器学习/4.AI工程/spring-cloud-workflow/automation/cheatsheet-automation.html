3 个 Hooks 自动推进

🪝 Hook 1: 阶段跟踪

UserPromptSubmit · stage-tracker.py
  • 检测用户输入关键词
  • 自动推进状态机
  • 状态写入 /tmp/req-state.json
  • 8 阶段 × N 关键词

🪝 Hook 2: 文档验证

PostToolUse(Write) · doc-validator.py
  • CC 写 0X-*.md 后自动跑
  • 验证 8 个模板必填字段
  • 不达标 stderr 提示
  • 不阻断主流程

🪝 Hook 3: 覆盖率

PostToolUse(Bash) · coverage-check.py
  • mvn test 跑完自动跑
  • 读 JaCoCo CSV 报告
  • Service ≥ 80% 硬指标
  • 不达标强提示补测试

4 步安装(5 分钟)

# 1. 复制文件(1 分钟)
cd ~/projects/order-service
mkdir -p .claude/commands .claude/hooks
cp <toolkit>/automation/.claude/commands/req-full.md .claude/commands/
cp <toolkit>/automation/.claude/hooks/*.py .claude/hooks/
cp <toolkit>/automation/.claude/settings.json .claude/
chmod +x .claude/hooks/*.py

# 2. 改 settings.json 路径(2 分钟)
# 把 $CLAUDE_PROJECT_DIR 替换成绝对路径
# /home/user/projects/order-service/.claude/hooks/...

# 3. 测试 hooks(1 分钟)
echo '{"user_prompt":"test"}' | python3 .claude/hooks/stage-tracker.py

# 4. 启动(1 分钟)
claude
> /req-full REQ-2026-001 满100减20

故障排查

Hook 不触发?

  • 检查 settings.json 路径
  • 检查 chmod +x
  • 检查 python3 解释器

状态推进不对?

  • cat /tmp/req-state.json
  • 删掉重置: rm /tmp/req-state.json
  • 改 STAGE_TRIGGERS 关键词

覆盖率不准?

  • 报告路径: target/site/jacoco/jacoco.csv
  • 多模块:每个模块各一个
  • 改 classify_package

Hook 跑得慢?

  • 每个 hook < 500ms 目标
  • 检查 Python 启动慢(可用 uv)
  • 检查 I/O 多(可加缓存)
