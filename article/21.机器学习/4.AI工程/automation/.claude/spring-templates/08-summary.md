## 4. 踩过的坑(给后人)

### 坑 1:BigDecimal 比较要用 compareTo

**时间**:T2.2 实现时
**症状**:
```java
// ❌ 错误:用 == 比较 BigDecimal
if (orderAmount == rule.getThreshold()) { ... }
// 99.99 != 99.99 因为 BigDecimal 有 scale
```

**修正**:
```java
// ✅ 正确
if (orderAmount.compareTo(rule.getThreshold()) >= 0) { ... }
```

**教训**:BigDecimal 比较必须用 compareTo,等号、equals 都有坑

### 坑 2:Testcontainers 启动慢

**时间**:T3.4 集成测试
**症状**:第一次跑集成测试 30 秒,后面变 5 秒
**原因**:Testcontainers 第一次需要拉镜像
**修正**:
- 团队 CI 镜像预热
- 本地用 `singleton container` 而不是 `@Container`

### 坑 3:Redis 锁的 TTL 要看业务耗时

**时间**:T3.1
**症状**:业务执行 8 秒,锁 5 秒 TTL 过期
**修正**:用 Redisson 看门狗(见决策 D1)
