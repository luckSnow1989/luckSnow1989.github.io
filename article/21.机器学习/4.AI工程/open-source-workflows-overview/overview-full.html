4 个灵魂问题

1. 工具 vs 产品?

  • 工具(给开发者):A 路线
  • 产品(给用户):B 路线

2. 项目阶段?

  • 探索期(0→1):Coze / Flowise / Waza
  • 验证期(1→10):Dify / n8n / Superpowers
  • 增长期(10→100):Ruflo / CE / RAGFlow+Dify
  • 成熟期(100+):LangGraph / 自研

3. 数据主权?

  • 必须本地:自托管平台
  • 避开:Coze(平台托管)
  • 不强求:都 OK

4. 商业模式?

  • 自用:任何平台都 OK
  • SaaS 卖:避开 n8n / Dify 多租户
  • 推荐:LangGraph / RAGFlow / Flowise

2 大河交叉点(神级组合)

🅰 A 河 ↔ 🅱 B 河 怎么打通?

用 A 河(Claude Code 生态) 写代码,产出 MCP server / API;
用 B 河(通用平台) 把这些 API 集成到业务流程里。

例子:Claude Code + Superpowers 写好一个「文档解析 MCP Server」 → Dify 工作流调用它 → n8n 触发「收到新文档就解析入库」 → RAGFlow 提供检索
